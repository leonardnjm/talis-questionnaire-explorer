# Privacy policy: TALIS Questionnaire Explorer

Last updated: <date>

TALIS Questionnaire Explorer is a read-only connector that returns content from the published TALIS questionnaires. It is run by <your name> as an independent project.

## What data is collected

- **No accounts.** There is no sign-up or sign-in, and the connector asks for no personal information.
- **Tool requests.** When your AI assistant uses the connector, it sends the tool name and its parameters (for example a search term or a question key). These are processed only to return the answer.
- **Technical logs.** The hosting platform records standard request logs (time, tool called, response status and network information such as IP address) for operating, securing and debugging the service.

The connector does not receive your conversation with the assistant, only the specific tool requests the assistant chooses to send.

## How it is used

Request data is used only to return results and to keep the service running and secure. It is not used for advertising, profiling or training models, and it is not sold.

## Storage and retention

The service is hosted on Microsoft Azure in the France Central region (EU). Technical logs are kept for <N> days and then deleted.

## Sharing

Data is not shared with third parties, except the hosting provider (Microsoft Azure) acting on my behalf, or where required by law.

## Your AI assistant

Your conversation is handled by the assistant you use (for example Claude or ChatGPT) under that provider's own privacy policy.
